# Infernofest

És una pàgina web estàtica per presentar Infernofest, un festival de música a Lleida. Inclou informació sobre l'esdeveniment, l'itinerari, els patrocinadors, preguntes freqüents, contacte, registre i polítiques.

## Tecnologies

HTML5
CSS3
Firebase Hosting

## Obrir localment

Es pot obrir localment posant 'http-server' a la Terminal que donarà un enllaç que es pot obrir al navegador. [http://192.168.1.152:8080](http://192.168.1.152:8080)
